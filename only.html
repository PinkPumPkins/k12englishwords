1️⃣ 五维拆解法

形·拼写only —— one（一）+ ly（…地）→ 只有一个地
✏️ 口诀：only 里有 one，只有这一个！
音·发音/ˈəun.li/ 重音在前，/əʊ/ 圆唇
🎧 跟读：Only five yuan. · only one
意·释义只；仅仅（强调数量少或范围小）
用·句型① Only five yuan just for today. (今天只要五元。)
② I have only one pencil. (我只有一支铅笔。)
③ Only you can open it. (只有你能打开它。)
④ The shop is open only today. (商店只开今天。)
拓·同族词对照记忆：a lot 很多 —— only 是“少”，a lot 是“多”，购物广告两兄弟

句型句子

📋 功能句总结 · only 的位置魔法

only 放的位置不同，意思就变：
Only I love you.（只有我爱你）
I only love you.（我只是爱你）
I love only you.（我只爱你一个人）

👨‍👩‍👧 家长指导卡

only 是广告最爱用的词——Only five yuan! 让东西显得超便宜。带孩子读超市传单找 only，体会它的“促销魔法”。语法上只需记住一条：only 靠谁近修饰谁，位置一换句子意思就变，用例句对比着念最直观。

📖 微型故事《只要五元》

🏷️ 文具店门口贴着大海报：Only five yuan just for today! 小熊冲进去：“I want it! I want it!” 妈妈问：“What do you want?” 小熊一看，原来是卷笔刀。“A pencil sharpener, only five yuan. I have five yuan. It fits!” 妈妈笑了：only 的魔力，让五元也能当大款。

🧑‍🏫 家长提问卡：
• 海报上写着什么？(Only five yuan just for today!)
• 小熊买了什么？(A pencil sharpener.)
• 问问孩子：If you have only five yuan, what will you buy?

🗺️ 思维导图

only 只；仅仅
├── 构成 ── one（一）+ ly → 只有
├── 广告 ── Only five yuan!（只要五元）
├── 位置 ── 靠谁近修饰谁
├── 句型 ── I have only one... / Only you...
└── 对照 ── a lot 很多（多与少）

🏛️ 词源故事

only = one（一）+ -ly，字面意思“只有一个地”。它和 alone（独自，all + one）是表兄弟，都藏着“一个”。所以 only 从出生那天起，就带着“独一无二、不多不少”的意思。🎯 讲给孩子：看见 only，就看见里面的 one。

🎵 歌词里的 only

🎵 The Platters《Only You》(1955)：doo-wop 传世经典，“Only you” 深情典范——千万人中，only 一个你。

⚡ 冷知识

only 是英语里出了名的“位置敏感词”。经典例子：Only I love you（只有我爱你）、I only love you（我只是爱你——可能还没到承诺未来）、I love only you（我只爱你一个人）。同样三个词，only 挪一下位置，句子的意思完全不同——写作文时千万注意它站哪儿。
