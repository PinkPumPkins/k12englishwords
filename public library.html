1️⃣ 五维拆解法

形·拼写pub·lic + li·brar·y —— public 人民的 + library 书的房子；library 里藏着两个 r，拼写别丢
音·发音/ˌpʌblɪk ˈlaɪbrəri/ library 重音在 LI
🎧 跟读：in the public library · borrow books from the library
意·释义公共图书馆（供全民免费使用的图书馆）
用·句型① There is a public library near my home.
② I read books in the public library.
③ You can borrow books from the library.
④ Be quiet in the library!
拓·同族词public 家族：in public 公开地 · publish 出版；library 家族：librarian 图书管理员 · library card 借书证

📢 拓展跟读表（课外句 · 非课本原文）

句型句子
存在There is a public library near my home.
活动I read books in the public library every weekend.
借阅You can borrow books from the library.
规则Be quiet in the library!
功能句总结 · borrow 与 lend

borrow from（借入）：You can borrow books from the library.

lend to（借出）：The library lends books to everyone.

keep 表借多久：You can keep the book for two weeks.

⚠️ borrow 是“借入”，方向别弄反！

👨‍👩‍👧 家长指导卡

办一张少儿借书证，就是 public library 的最好实践。借书时让孩子说 I'd like to borrow these books，还书说 I'm returning the books。顺便讲公共规则：Be quiet. No food in the library. 公共场所的英文礼仪一次学会。

📖 微型故事《免费的书屋》

Ted 带路经过一栋安静的大楼：“Over there you can see a public library.” Bill 好奇：public 是什么意思？Ted 说：“public 就是大家的——不用花钱，人人都能进去看书、借书。”Bill 借了三本书，管理员说：You can keep them for two weeks. Bill 感叹：世界上最好的商店不卖东西，只借故事。

🧑‍🏫 家长提问卡：
• public library 好在哪里？（免费向公众开放）
• 借书用哪个动词？（borrow...from）
• 在图书馆要遵守什么规则？（Be quiet 等）

🗺️ 思维导图

┌── 构词 ── public(公众的) + library(书房) ├── 词源 ── liber 拉丁“树皮/书”——古人在树皮上写字 ├── 用法 ── borrow from 借入 · lend to 借出 · keep for 借多久 ├── 家族 ── librarian 图书管理员 · library card 借书证 └── 本课 ── Over there you can see a public library.

🏛️ 词源故事

library 出自拉丁语 librarium（书柜、书房），词根 liber 本义“内树皮”——古罗马人最早在树皮上写字，树皮慢慢变成“书”的代称。public 出自拉丁语 publicus（人民的），与 people 同根。两个词一拼：属于人民的书的房子。🎯 讲给孩子：图书馆是人类最早的“共享书房”。

⚡ 冷知识

多伦多公共图书馆是加拿大最大的公共图书馆系统，分馆上百家，也是北美最繁忙的图书馆系统之一——Bill 在课本里路过的那栋楼就有真身。而“借书要还”的规矩，让图书馆成了人类最早的“共享经济”。
