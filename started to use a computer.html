🟢 低阶 · 学生自习室
📌 背诵 + 自测 | 课本同步跟读

1️⃣ 五维拆解法

形·拼写use + a computer —— use 以 e 结尾，加 ing 去 e：using；a 不能丢
✏️ 口诀：use 用起来，a computer 别丢 a
音·发音/ˈstɑːtɪd tə juːz ə kəmˈpjuːtə/ 重音在 -pu-：com-PU-ter；use 作动词尾音 /z/
🎧 跟读：When did you start to use a computer?
意·释义开始用电脑：use 用（工具）；第一次摸电脑、打字、玩画图，都是成长刻度
用·句型① When did you start to use a computer, Joy? (Joy，你什么时候开始用电脑的？)
② — When I was four. What about you? — I started when I was six.
③ I use a computer to do my homework. (我用电脑做作业。)
④ Use it carefully. (小心使用。)
拓·同族词use 家族：useful 有用的 · user 用户；电脑家族：play computer games 玩电脑游戏；started 家族（同在本单元）

📢 拓展跟读表（课外句 · 非课本原文）

句型句子
成长I started to use a computer when I was four.
问答— When did you start to use a computer? — At six. What about you?
用途I use a computer to draw pictures.
习惯I use the computer for one hour a day.
功能句总结 · use 的两读两用

动词 use /juːz/：What do you use it for?（你用它做什么？）
名词 use /juːs/：It's no use crying.（哭没有用。）

本单元句：When did you start to use a computer? —— use 是动词，读 /juːz/。

👨‍👩‍👧 家长指导卡

电子产品是当代成长记录的必选项。建议和孩子做“家庭科技时间轴”：家长说 I started to use a computer when I was...（很可能是十几岁甚至更晚），孩子说自己的一句，对比中自然引出“技术变了，成长的事没变”。发音提醒：use 作动词读 /juːz/，尾音是浊音。

📖 微型故事《Dad's First Computer》

家庭旧物日，爸爸搬出一台方头方脑的老电脑：I started to use a computer when I was sixteen — it couldn't even show pictures! Tom 睁大眼睛：No pictures? 爸爸按下老键盘，屏幕跳出一行绿色字母，父子俩对着黑屏笑作一团。Tom 说：I started when I was six. 爸爸说：So you grew up with colors, and I grew up with words. 两台电脑，两段童年。

🏛️ 词源故事

computer 来自拉丁语 computare（一起计算），17世纪时它指“会算账的人”——人工计算员。1946年亮相的第一台电子计算机 ENIAC 重约27吨，占了整间屋子，操作它的却是六位女程序员。use 来自古英语，是最古老的常用词之一。🎯 讲给孩子：computer 本来是“算账的人”的职称，后来机器抢走了这个头衔。

电脑是心灵的一辆自行车。——史蒂夫·乔布斯。第一次用电脑的人，都推开了一扇新世界的门。

⚡ 冷知识

第一台电子计算机 ENIAC 重约27吨，约等于6头大象；今天一块手表芯片的算力是它的亿倍。鼠标1968年才当众亮相，最早的样子是个带两个轮子的木头盒。Joy 四岁 start to use a computer，在1946年是不可思议的事——你的“四岁”，站在几十年技术进化的肩膀上。
