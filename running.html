1️⃣ 五维拆解法

形·拼写run·ning —— run 是重读闭音节（辅+元+辅），双写 n 再加 ing
✏️ 口诀：闭音节尾巴短，双写字母再加 ing！
音·发音/ˈrʌn.ɪŋ/ 两音节，重音在前：RUN-ning
🎧 跟读：I like running. · go running · running shoes
意·释义跑步 🏃（run 跑 + ing，动作变成名词）
用·句型① I like running. (我喜欢跑步。)
② Running is fun. (跑步很有趣。)
③ He is good at running. (他擅长跑步。)
④ I often go running in the park. (我常去公园跑步。)
拓·同族词run → running（动名词）→ runner（跑步者；跑鞋）
同单元运动词：jumping rope 跳绳 · roller skating 滑旱冰 · ping-pong 乒乓球

📋 功能句总结 · like + doing（喜欢做某事）

like / love / enjoy + 动词ing：
I like running 🏃 / I love swimming 🏊 / I enjoy reading 📖

⚠️ 三单别忘了：
He likes running. / She loves jumping rope.

💡 like 后面的动词要穿 ing 这件外衣，主语三单时 like 要加 s！

👨‍👩‍👧 家长指导卡

四年级上册 Unit 1 第一课就是运动词汇。建议在家玩“运动模仿秀”：家长说 running 全家原地跑，说 jumping rope 假装跳绳，说 roller skating 踮脚滑——单词和动作绑在一起记得最快。纠正重点：running 双写 n，别写成 runing。

🟡 中阶 · 家长加油站
👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《The Boy Who Runs to School》

🏃 小杰每天都 get up 晚。闹钟响第一遍，他把头埋进被子：Five more minutes! 等他跳下床，早饭只来得及咬一口面包。于是每天清晨，小区里都能看见一道风——小杰一路 running 冲向学校。体育课跑步比赛，他竟然拿了第一名！老师问他秘诀，他喘着气说：Because I get up late every day! 全班都笑了。妈妈说：那明天我们试试 get up early，看看你还能不能得第一？

🧑‍🏫 家长提问卡：
• Why does the boy run to school every day? (Because he gets up late)
• What did he win at school? (A running race)
• 问问孩子：What time do you get up? Is it early or late?

🗺️ 思维导图

┌── 动作 ── run fast / go running / run to school
├── 频率 ── often 经常 / every day 每天 / sometimes 有时
├── 装备 ── running shoes 跑鞋
├── 家族 ── runner 跑步者 · 双写 n 加 ing 规则
└── 课本句 ── I often run from home to school, because I often get up late.

🏛️ 词源故事

run 是英语里最古老的动词之一，古英语里写作 rinnan，已经“跑”了上千年。running 由 run 双写 n 加 ing 构成——因为 run 是重读闭音节，尾巴要“踩实”。有趣的是，run 还是英语含义最多的动词之一：run a company（经营公司）、run out of milk（牛奶喝完了）、My nose is running（流鼻涕）——一个词跑遍生活。
🎯 讲给孩子：run 不只会跑步，还会“经营”和“流鼻涕”！

📜 名言 & 谚语

Faster, Higher, Stronger – Together.
更快、更高、更强——更团结。—— 奥林匹克格言，写给每一个爱奔跑的人。

🎵 歌词里的 running

🎵 Bruce Springsteen《Born to Run》(1975)：摇滚工人皇帝的传世名曲，歌名就是“生来奔跑”，副歌的鼓点像脚步一样追着人跑。🔗 与 run 页互链（同歌）

⚡ 冷知识

马拉松为什么不多不少正好 42.195 公里？1908 年伦敦奥运会，为了让英国王室在包厢里看到起跑，赛道从温莎城堡一直量到皇家包厢正前方——这个“将错就错”的距离后来成了全世界马拉松的标准。科学家还说：人类天生是长跑高手——论冲刺跑不过猎豹，但论“跑得久”，我们靠全身出汗降温，能把猎物一直“耗”到跑不动。
