1️⃣ 五维拆解法

形·拼写f·ast 同族：past / last / task——都含 -ast
✏️ 口诀：f 打头，ast 收尾，快人一步
音·发音/fɑːst/ 长音 /ɑː/ 加清脆的 /st/
🎧 跟读：run fast · a fast car · fast food
意·释义迅速的（形容词）；快地（副词）——一词两用：a fast horse（快马）/ run fast（跑得快）
用·句型① Horses can run fast. (马跑得快。)
② The cheetah is the fastest animal on land. (猎豹是陆地上最快的动物。)
③ I like fast food. (我喜欢快餐。)
④ Don't run so fast! (别跑那么快！)
拓·同族词fast food 快餐 · fast asleep 睡得沉 · hold fast 牢牢抓住（这里 fast=牢固！）；反义：slow 慢

📢 拓展跟读表（课外句 · 非课本原文）

句型句子
能力A horse can run very fast.
比较The cheetah runs faster than the horse.
提醒Don't run so fast!
习语The baby is fast asleep.
功能句总结 · fast 是"形容词+副词"双面词

形容词：a fast horse（快马）——修饰名词

副词：run fast（跑得快）——修饰动词，注意副词不加 ly！

比较级：fast → faster → fastest（run faster 跑得更快）

⚠️ 英语里根本没有 fastly 这个词——fast 的副词还是 fast！

👨‍👩‍👧 家长指导卡

fast 是五年级重点"双面词"：既能当形容词（a fast car），又能当副词（run fast），而且副词形式不加 -ly——这是孩子最容易犯错的地方。建议玩"快慢口令"游戏：跑步时喊 Run fast! / Walk slowly!，用身体记住两种词性。顺便讲 fast asleep、hold fast 里 fast 的"牢固"义，拓展词感。

📖 微型故事《Fast and Steady》

🐴 农场运动会，小马宣布："I'm fast! I can run faster than everyone!" 乌龟慢悠悠："Slow and steady wins the race, remember?" 小马大笑："That's just a story!" 比赛开始，小马一路领先，可它太得意，跑错了弯道，等发现时只好掉头往回跑。乌龟一步一步爬过了终点线。小马挠挠头："Maybe fast isn't everything. Next time, fast AND steady!"

🧑‍🏫 家长提问卡：
• 谁赢了比赛？(The tortoise)
• 小马为什么会输？(It took the wrong turn / too proud)
• 问问孩子：What does "Slow and steady wins the race" mean?

🗺️ 思维导图

┌── 双面词 ── a fast horse（形）· run fast（副，不加ly）
├── 三级 ── fast → faster → fastest
├── 词组 ── fast food 快餐 · fast asleep 睡沉 · hold fast 抓牢
├── 反义 ── slow 慢 · slowly 慢慢地
└── 伙伴 ── horse 马（本单元的 fast 明星）

🏛️ 词源故事

fast 最早的意思是"牢固的"（古英语 fæst）——今天 hold fast（抓牢）、stand fast（站稳）、fast asleep（睡得沉）里还保留这层意思。"快"是从"牢牢地、使劲地"演变来的：跑得又稳又猛，自然就快了。breakfast（早餐）= break + fast（打破一夜不进食的"斋戒"）。
🎯 讲给孩子：fast 的本义是"牢"，"快"是它跑出来的新义。

📜 名言 & 谚语

"Slow and steady wins the race."（稳扎稳打才能赢。）—— 出自伊索寓言《龟兔赛跑》，英语世界最著名的励志谚语之一。

🎵 歌词里的 fast

🎵 Eagles《Life in the Fast Lane》(1976)：老鹰乐队传奇摇滚，"快车道上的人生"——fast lane 就是高速公路的超车道。与 horse 页互链：马儿跑得 fast！

⚡ 冷知识

陆地上最快的动物是猎豹，冲刺时速可超 100 公里——但只能坚持几十秒；鸵鸟是跑得最快的"两脚兽"，时速约 70 公里，却能跑上半小时。英语里 fast 还有个反直觉用法：钟表 "fast" 是指"走快了"（The clock is fast），说的是"超前"，不是"迅速"。
