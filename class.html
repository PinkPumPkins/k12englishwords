📖 课本原文直通车 · Unit 1 Myself

Lesson 1
My name is Sue. I'm new here.
I'm nine years old. I want to be your friend.
— Hello, you are new. What's your name and how old are you?
— Hello, I'm new. My name is Sue and I'm nine years old.
— Hello. My name is Jack. I'm eight years old. I want to be your friend, too!

Lesson 2
— What's your name? — I'm Sue.
— How old are you? — I'm nine years old.
— Which class are you in? — I'm in class two.

Lesson 3 · 书信
Hello, My name is Harry. I'm a boy. I'm in class one, grade three. I'm nine years old. I want to be your friend. Yours, Harry
（回信）Dear Harry, Let's be friends. Yours, ...

Let's Check
Hello! My name is Mary. I'm ten years old. I'm in class one.
I'm Mike. I'm nine years old. I'm in class two.

🟢 低阶 · 学生自习室
📌 背诵 + 自测 | 课本同步跟读

1️⃣ 五维拆解法

形·拼写c·l·ass —— cl 像两个同学手拉手。✏️ 口诀：cl 拉手进 class，ass 结尾别念散，重音在前：CLASS！
音·发音/klɑːs/ 英式长音 /ɑː/，美式读 /klæs/。🎧 跟读：class one · in class · after class
意·释义班级 🏫（也指一节课：have an English class 上英语课）
用·句型① Which class are you in? (你在几班？)
② I'm in class one. (我在一班。)
③ We have an English class today. (今天我们有英语课。)
④ Class begins. 上课了！
拓·同族词classmate 同班同学（class+mate 伙伴）· classroom 教室（class+room 房间）· first class 头等舱/第一流的

📋 功能句总结 · Which class are you in?

问班级：
— Which class are you in?
— I'm in class one. 我在一班。

⚠️ 中英班级顺序相反：
中文：三年级一班
英语：Class One, Grade Three（先班后年级）

👨‍👩‍👧 家长指导卡

class 在本单元和 grade 是黄金搭档。建议做一张“班级卡片”贴在书桌上：Class One, Grade Three，孩子每天读一遍。再区分三个“班”：class 班级、classroom 教室、classmate 同学——对着教室门牌和同学拍照对应，一词一图。重点纠正：在班级里用 in，I'm in Class One，不说 I'm at Class One。

📖 微型故事《The New Classmate》

🏫 周一早上，班上来了个新同学。老师说：“Please introduce yourself.” 女孩大大方方：“Hello! I'm Sue. I'm nine years old. I'm in Class Two, Grade Three. I want to be your friend.” 下课后，同学们围上来：“Welcome to Class Two!” 新教室一下子热闹起来——原来一个 class 不只是门牌号，还是一群等着你认识的小伙伴。

🧑‍🏫 家长提问卡：
• How old is Sue? (Nine years old)
• Which class is Sue in? (Class Two, Grade Three)
• 问问孩子：如果班里来了新同学，你想对他/她说什么英语？

🏛️ 词源故事

class 来自拉丁语 classis，两千多年前是古罗马给全体公民分等级的词，罗马人还用它给舰队分类。18世纪起，学校用它指“编在一起上课的学生”。🎯 讲给孩子：class 这个词走了两千年，从罗马广场一路走进了教室。

🔍 构词密码

词构成与含义
classroomclass + room → 教室
classmateclass + mate（伙伴）→ 同班同学
first class头等舱；一流的：fly first class 坐头等舱
after class课后：We play games after class.

📜 名言 & 谚语

“in a class of one's own” 🏆
独一档、无人能及——字面是“自己一个人占一个班”，用来夸某人或某物出色到没有对手。

🎵 歌词里的 class

🎵 Jack Harlow《First Class》(2022)：Billboard 空降冠军，歌名里的 first class 一词多义——既是“头等舱”也是“第一流的”。本页主角 class 就藏在歌名里。

⚡ 冷知识

英语国家上课铃响说 Class begins!（上课），下课说 Class is over!。class 还能当“等级”：飞机有 first class 头等舱、economy class 经济舱。另外，美式英语的“年级”用 grade，英式用 Year 3——同一个年级，各国叫法大不同，下一篇 grade 页细讲。
