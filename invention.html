1️⃣ 五维拆解法

形in·ven·tion = in (进入) + vent (来) + ion (名词) — 引入新事物 → 发明
✏️ 口诀：发明invention，就是"引进(vent)来(ion)"新东西！
音/ɪnˈvenʃən/ 三音节 → in·ven·tion
重音在第二音节：/ɪnˈVEN-shən/
🎧 跟读：What an amazing invention! People invented paper.
意发明；发明物、创造 🎨
用What an amazing invention! (多神奇的发明！)
People invented paper 2000 years ago. (人们2000年前发明了纸。)
Edison's inventions changed the world. (爱迪生的发明改变了世界。)
拓invent (v.) → invention (n.) → inventive (adj. 有创造力的)
同款：create → creation → creative

📖 微型故事《The Amazing Paper Scroll》

📜 古代有个孩子问老师："以前没有纸，人们怎么写字？"老师答："他们用竹子、丝绸！但大约2000年前，蔡伦发明了纸——What an amazing invention！"孩子惊叹："That's amazing！那在没有纸之前，人们岂不是要背很多竹子？" 老师笑了："是啊，所以你要珍惜纸。纸的发明改变了整个世界！"

🗺️ 思维导图 · invention 世界

核心句型: What an amazing invention! / That's amazing! 发明家: Cai Lun (蔡伦) / Edison / Bell 四大发明: paper / printing / compass / gunpowder 词族: invent (v.) → invention (n.) → inventive (adj.)

🏛️ 词源故事：从"走进"到"发明创造"

invention 来自拉丁语 invenire（发现、找到），由 in（进入）+ venire（来）构成。本意是"走进（未知领域）找到新东西"。想象科学家走进实验室，发现了一个前所未见的东西——这就是 invention（发明）。

🎯 讲给孩子：in-是"进入"，vent是"来"——走进一个领域，发现新东西，就是"发明"！

🔍 构词密码

in + vent + ion → invention。in-表示"进入"，vent表示"来"，-ion表示"行为及其结果"。

单词释义词根
invent发明in进入 + vent来
invention发明物invent + ion
inventive有创造力的invent + ive
prevent阻止pre前 + vent来 → 先来一步 → 阻止

⚡ 冷知识 · 蔡伦：改变世界的发明家

蔡伦是东汉时期的宦官，他在公元105年改进了造纸术，用树皮、破布等便宜材料制作纸张，成本低、质量好，迅速传播到全世界。没有蔡伦的发明，就不会有今天的书本、报纸和作业本——What an amazing invention!
