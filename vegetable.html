核心句型: I like vegetables. / How about some vegetables? 蔬菜种类: tomato / potato / carrot / cabbage / broccoli / spinach 健康话题: Vegetables are healthy. / Good for health. 相关词汇: fresh / healthy / green / buy / eat

🏛️ 词源故事：从"活力"到"蔬菜"

vegetable 来自拉丁语 vegetabilis（有生命力的、能生长的），由 vegetare（使充满活力）+ -abilis（可...的）构成。最初的 vegetable 指的是"任何能生长的植物"，后来范围缩小特指"蔬菜"。中文"蔬菜" = "蔬"（菜的可食部分）+ "菜"（植物），也是强调"可以吃的植物"。

🎯 讲给孩子：vegetable 来自"充满活力"——蔬菜让我们的身体充满活力，所以要多吃蔬菜！

🔍 词根解析：veg- 系列词汇

vegetable = veget (使充满活力) + able (可...的) → 可以给身体注入活力的东西 → 蔬菜

⚡ 冷知识 · 为什么大力水手吃菠菜？

大力水手Popeye吃菠菜后变得超级强壮的故事深入人心！实际上菠菜确实营养丰富：富含铁、维生素A、维生素C和叶酸。但它的铁含量并没有传说中那么神奇——这个误解来自1870年代科学家的小数点计算错误！不过菠菜确实是健康蔬菜，小朋友们要多吃哦！
