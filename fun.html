🟢 低阶 · 学生自习室
📌 背诵 + 自测 | 课本同步跟读

1️⃣ 五维拆解法

形·拼写f + u + n，三个字母的最短评价词之一
✏️ 口诀：fun 是 fun，词尾 n 别写成 m
音·发音/fʌn/ 短促有力；与 fan /fæn/（扇子）一音之差
🎧 跟读：It's fun! · have fun · funny
意·释义有趣的；乐趣 🎉（形容词'好玩'，名词'乐趣'；funny 是'滑稽好笑'）
用·句型① It's fun! (很有趣！)
② We have fun on the weekend. (我们周末玩得开心。)
③ The game is great fun. (这个游戏真好玩。)
④ What fun! (多有意思呀！)
拓·同族词fun → funny 滑稽的；make fun of 取笑；have fun 玩得开心；for fun 为了好玩

句型句子

📋 功能句总结 · fun vs funny
fun：让人快乐、好玩（正面的'有趣'）
The party is fun. 派对很好玩。
funny：滑稽的、好笑的（让人发笑）
The clown is funny. 小丑很滑稽。
⚠️ 固定搭配：have fun（玩得开心）/ make fun of（取笑）
👨‍👩‍👧 家长指导卡

fun 是孩子最爱的评价词——夸什么都 It's fun! 可以顺势教对比：fun（好玩）不等于 funny（滑稽）。玩滑梯是 fun，小丑摔跤是 funny。再教 have fun 用于告别：Have fun at the party! 每次孩子出门玩，家长说 Have fun!，孩子回 Thank you!——一个惯用句就练成了。

🏛️ 词源故事

fun 是个'从愚人变乐子'的词：16 世纪它从动词 fon（愚弄、开玩笑）演变而来，最初指'捉弄、骗局'——make fun of（取笑）里还留着这层老味道。到 18 世纪，fun 才慢慢变成今天'快乐、乐趣'的中性义。美国乐队 fun. 干脆把这个最短的快乐词变成名字，还特意带上句点，让 fun 名副其实。
🎯 讲给孩子：fun 一路从'愚弄'走到'欢乐'，是个洗心革面的词。

📜 名言 & 谚语

"Fun is good." 🎈
快乐是好事。—— 童书大师苏斯博士（Dr. Seuss）广为流传的短句，三个词说尽了快乐的哲学。

🎵 歌词里的 fun

🎵 fun.《We Are Young》ft. Janelle Monáe (2012)：Billboard 六周冠军，乐队名就叫 fun.（自带句点）——歌名即乐队名的双关，唱的是'今夜我们正年轻'的肆意快乐。

⚡ 冷知识

英语里最短的快乐词 fun 只有 3 个字母，但它的'家族'很庞大：funny（滑稽）、funfair（游乐场，英式）、fun run（趣味跑）。美国乐队 fun. 的名字里那个句点是真的——官方写法必须带点，歌迷打字都不敢漏。另外，fun 在 16 世纪刚出现时其实是'愚弄'的意思，'拿某人寻开心'的 make fun of 保留了这个原始用法——所以取笑别人可不算 fun 哦。
