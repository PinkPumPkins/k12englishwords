🟢 低阶 · 学生自习室
📌 背诵 + 自测 | 课本同步跟读

1️⃣ 五维拆解法

形·拼写l·ike —— l + i + k，中间 i 读“爱”的音 /aɪ/
✏️ 口诀：like 里有个“爱”（i /aɪ/），喜欢自然把爱装
音·发音/laɪk/ 单音节，双元音 /aɪ/ 要饱满
🎧 跟读：I like apples. / I like bananas.
意·释义喜欢 💚（本课重点）；也作“像”：He is like his dad. 他像他爸爸（高年级学）
用·句型① I like apples. (我喜欢苹果。)
② Do you like bananas? (你喜欢香蕉吗？)
③ They are all good to eat. (它们都很好吃。——chant 同句)
④ I like this pear. (我喜欢这颗梨。)
拓·同族词like → likes（三单）· dislike 不喜欢 · would like 想要（更礼貌）
彩蛋：社交软件的“点赞”就叫 like；副词后缀 -ly 与 like 同源（“有…的样子”）

📢 拓展跟读表（课外句 · 非课本原文）

句型句子
喜好I like apples.
提问Do you like bananas?
礼貌表达I would like a pear, please.
比喻The moon is like a banana.
📋 功能句总结 · like 后面跟什么
like 一整类水果 → 用复数：
I like apples. 🍎 / bananas 🍌 / oranges 🍊
like 某一个具体的 → 用单数：
I like this apple. / I like the pear.
⚠️ 课本 chant 全是复数：like 讲的是“一整类都爱”。
👨‍👩‍👧 家长指导卡

like 是本单元的“动词主角”，chant 里四连发。生活里随时可用：吃到喜欢的水果就说 I like bananas!，不喜欢的说 I don't like…，立刻变成亲子口头禅。盯紧两个高频错误：一是 like 后忘加 s（I like apple ✗）；二是答句漏 do。每天饭前一句 I like… 打卡，一周后孩子就能把整段 chant 唱出来。

📖 微型故事《The Like Collector》

💚 单词城来了个收“喜欢”的小精灵 like，背着口袋四处问：Do you like apples? 男孩答 Yes, I do.，like 就把一颗亮星星收进口袋。问遍全城：I like pears! I like oranges! I like bananas! 口袋渐渐装满。最后它照着镜子问：Do you like me? 镜子里全城人齐声喊：Yes, we do! like 的口袋一下子炸开，星星飞满天——原来把“喜欢”送出去，会收获更多。

🧑‍🏫 家长提问卡：
• What did the fairy collect? (Likes / little stars)
• What did the mirror answer? (Yes, we do!)
• 问问孩子：Do you like apples? 问问家人，收集三个回答

🗺️ 思维导图

┌── 本课句 ── I like apples. / Do you like bananas?
├── 搭配 ── like + 复数（一类）· like + this/the（具体）
├── 家族 ── likes 三单 · dislike 不喜欢 · would like 想要
├── 同源 ── -ly 后缀（“有…的样子”）· 点赞 like
└── 联想 ── 大拇指点赞手势

🏛️ 词源故事

like（喜欢）来自古英语 lician，本义是“使高兴”——一千年前句子是反着说的：Me liketh（直译“它取悦我”），主语是被喜欢的那个东西！后来句序才翻转成今天的 I like it.。有意思的是，另一个 like（像）和副词后缀 -ly 都出自“身体、形状”，本义“有…的样子”；两个 like 在古英语里本是两家人，读音越走越近才合体成同形词。🎯 讲给孩子：like 古代说“它喜欢我”，今天说“我喜欢它”，主客换了个位。

🔍 构词密码

词构成与含义
likes三单：She likes pears.（她喜欢梨）
dislikedis(不) + like → 不喜欢（反义兄弟）
would like想要（比 want 礼貌）：Would you like a pear?
-ly副词后缀，与 like 同源（“有…的样子”）：friendly 友好的

📜 名言 & 谚语

“Like father, like son.” —— 英语谚语（有其父必有其子）：like 在谚语里表示“像”，一词两义再添一证。

🎵 歌词里的 like

🎵 Bruno Mars《That's What I Like》(2017)：Billboard 冠军、2018年格莱美“年度歌曲”；歌名本身就是句口头禅——That's what I like!（这就是我喜欢的！），like 的双元音 /aɪ/ 唱着就记牢。（按歌名含词规则新配）
🎵 彩蛋：启蒙神曲 Super Simple Songs《Do You Like Broccoli Ice Cream?》直接把课本句型 Do you like…? 唱出来，亲子必听。

⚡ 冷知识

我们在手机上按的“点赞”按钮，英文就叫 like！2009年 Facebook 上线拇指按钮后，like 从一个普通动词变成全世界最常用的社交按钮之一——一个一年级单词，撑起了全球互联网的“好评系统”。另外 like、alike（相似地）、likely（可能的）是一家人，都从“样子”长出来。
