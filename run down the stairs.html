Lesson 1 · A. Look, listen and repeat

Play with fire? — Don't play with fire. Be careful!
Run down the stairs? — Be careful! Don't run down the stairs. It's dangerous!

Lesson 2 · A. Look, listen and repeat

Please wait for the green light. It's safe.
Don't read in the street. It's dangerous.

Lesson 3 · 读一读，写一写（五条安全规则）
① Please use the sidewalk. It's safe.
② Don't play with fire. It's dangerous.
③ Please wait for the green light.
④ Don't run down the stairs.
⑤ Don't climb on the window ledge.
⑥ The light is green. Please go.

1️⃣ 五维拆解法

形·拼写run + down + the + stairs 四段拼装
✏️ 口诀：down 往下，stairs 复数 s 挂尾——一级一级才叫 stairs
音·发音/rʌn daʊn ðə steəz/ down 的 /aʊ/ 要张大嘴
🎧 跟读：run upstairs · walk downstairs · take the stairs
意·释义跑下楼梯（run 跑 + down 向下）——课本用它示范危险动作；反义 climb up the stairs
用·句型① Don't run down the stairs. (别跑下楼梯。)
② It's dangerous! (很危险！)
③ Walk down the stairs slowly. (慢慢走下来。)
④ Hold the handrail, please. (请扶好扶手。)
拓·同族词upstairs 楼上 · downstairs 楼下；与 run 页互链；run down 还可指'撞倒、耗尽'

📢 拓展跟读表（课外句 · 非课本原文）

句型句子
劝阻Don't run down the stairs. It's dangerous!
安全Walk down the stairs and hold the handrail.
方位My bedroom is upstairs.
提醒More haste, less speed.
📋 功能句总结 · 走楼梯安全三句
第一句劝阻：Don't run down the stairs!
第二句方法：Walk slowly and hold the handrail.
第三句理由：It's dangerous. You might fall.
⚠️ 上楼下楼一个原则：走，不跑；扶，不空手！
👨‍👩‍👧 家长指导卡

楼梯是幼儿园和小学摔伤高发地。和孩子定下'楼梯家规'：一手扶扶手、一步一级、不打闹不推挤，并用英语互相提醒 Don't run down the stairs! 电梯同理：先出后进。把规则变成口头禅，孩子记得比家长还牢。

📖 微型故事《楼梯上的小火箭》

🚀 强强把自己当成小火箭，从三楼楼梯往下冲：Ten, nine, eight... Blast off! 姐姐在楼下大喊：Stop! Don't run down the stairs. It's dangerous! 强强刹住脚，扶着扶手一级一级走下来。姐姐发给他一张'安全宇航员'贴纸：Real astronauts walk first, then fly! 强强挺起胸脯：OK, I will walk like an astronaut!

🧑‍🏫 家长提问卡：
• What did Qiangqiang do? (Ran down the stairs)
• What did his sister say? (Don't run down the stairs.)
• 问问孩子：走楼梯三规则是什么？(走不跑、扶扶手、不打闹)

🗺️ 思维导图

┌── 方向 ── run down 向下跑 · run up 向上跑
├── 楼梯 ── stairs（复数）· handrail 扶手
├── 警示 ── Don't run down the stairs!

🏛️ 词源故事

stair 来自古英语 stæger，本义是'用来攀爬的东西'——最早的楼梯就是刻在山坡上的台阶。down 更妙：它来自古英语 dūn（小山），of dūne 意思是'从山上（下来）'，用着用着缩成了 down，'下山'变成了万能的'向下'。🎯 讲给孩子：down 的祖先是一座山，stair 的祖先是爬山的台阶。

📜 名言 & 谚语

“More haste, less speed.”
欲速则不达。—— 英语经典谚语。跑得越急，摔得越疼；慢慢走，反而先到。楼梯上的道理，人生路上也一样。

🎵 歌词里的 run down the stairs

🎵 Bruce Springsteen《Born to Run》(1975)：摇滚工人皇帝的传世名曲，生来要奔跑——但请记住：操场上 Born to run，楼梯上只能 walk！
🔗 与 run 页互链（同曲 Born to Run）。

⚡ 冷知识

走楼梯其实是免费的健身房：上楼消耗的能量约是平地行走的3倍。很多城市还有'爬楼大赛'（tower running），选手们冲刺上千级台阶，冠军往往不是腿最快的，而是节奏最稳的——又是 More haste, less speed！不过对小朋友来说，楼梯的唯一玩法是：扶好扶手，一级一级慢慢走。别学火箭，先学 astronauts walk。
