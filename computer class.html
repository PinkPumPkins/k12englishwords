1️⃣ 五维拆解法

形·拼写computer class 两个词一组：computer（电脑）+ class（课），中间留一个空格
✏️ 口诀：com-pu-ter 三音节，computer 会“计算”，class 是课堂集合号
音·发音/kəmˈpjuːtə klɑːs/ 重音在 pu；class 长音 /klɑːs/ 张大嘴
🎧 跟读：computer class · turn on the computer · type your name
意·释义计算机课（computer 还可指“电脑”本身；class 也指班级）
用·句型① We have computer class on Wednesday.（我们周三有计算机课。）
② Turn on the computer, please.（请打开电脑。）
③ Type your name.（打出你的名字。）
④ Time to rest your eyes!（该让眼睛休息啦！）
拓·同族词class 家族：classmate 同学 · classroom 教室 · class 班级/课/舱位（多义词）· computer games 电脑游戏

📋 功能句总结 · 课表播报员

问课表：What classes do you have on Monday? 周一你们有什么课？

播报：We have maths, PE and computer class. 我们有数学、体育和计算机课。

提醒：It's time for computer class. 到计算机课时间了。

⚠️ It's time for + 名词：It's time for class. 上课时间到！

👨‍👩‍👧 家长指导卡

computer class 是本单元最长的词组，拆成 computer + class 记。开机、打字、护眼用英语边做边说：Turn on the computer! / Type your name! / Rest your eyes! 定个“20-20”小约定：用屏幕 20 分钟就看看窗外远处的东西——远处的 that 正好复习。

📖 微型故事《第一次开机》

计算机课上，Bill 第一次自己开电脑。按下开机键，屏幕亮了！“哇——” 老师说：“Today we learn to use the computer. 先学坐姿：背挺直，眼睛离屏幕远一点。” Joy 打字打出自己的名字 “JOY”，兴奋地喊：“Look! My name is on the screen!” 老师提醒：“用电脑 20 分钟，就起来看看窗外。”

🧑‍🏫 家长提问卡：
• 开机前先学什么？(坐姿)
• Joy 在屏幕上打出了什么？(JOY 自己的名字)
• 问问孩子：用电脑/平板多久该休息眼睛？

🏛️ 词源故事

computer 来自拉丁语 computare（计算），字面就是“计算的家伙”。有趣的是，computer 一词最早指“做计算的人”——上世纪中期，NASA 的工程师们靠一群“人肉计算机”算轨道，其中就有电影《隐藏人物》里那几位非裔女数学家。class 来自拉丁语 classis，本是古罗马的“公民等级”与舰队。🎯 讲给孩子：computer 先是人，后是机器。

🎵 歌词里的 computer class

🎵 Kraftwerk《Computer Love》(1981)（CSV 已配 · 歌名含词）：电子乐先驱 Kraftwerk 的名曲，主题是对着屏幕找朋友——四十多年前就唱到了今天的生活！Coldplay 的《Talk》还借用了它的旋律。与 started to use a computer 页互链（同曲复用）。

⚡ 冷知识

世界上第一台通用电子计算机 ENIAC（1945 年诞生）重约 27 吨、占地约 170 平方米——差不多一间教室那么大！如今一部手机的计算能力早已超过它。计算机课上的小小电脑，是几十年间从“一屋子”缩小到“一双手”的奇迹。
